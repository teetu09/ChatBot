# 🧠 AI Mental Health Buddy

## 💡 Problem
- Mental health struggles are rising globally.  
- Therapy is costly, stigmatized, and inaccessible.  
- People often need immediate support, anytime and anywhere.  

## ✅ Solution
Our project is an **empathetic AI-powered wellness buddy** that:  
- Listens to users 24/7 in a safe and judgment-free way.  
- Provides stress management tips, journaling prompts, and mood tracking.  
- Includes guided relaxation (breathing exercises, affirmations).  
- Detects crisis keywords and shows emergency helpline support.  

## ✨ Features
- 🧠 AI Chatbot with empathetic conversations  
- 📊 Daily Mood Tracking dashboard  
- 📝 Journaling prompts for self-reflection  
- 🎧 Relaxation tools (breathing exercises, positive affirmations)  
- 🚨 Crisis detection + helpline integration  
- 🌍 Future scope: multilingual support & gamification  

## 🛠️ Tech Stack
- **Frontend:** React + TailwindCSS  
- **Backend:** Python (Flask/FastAPI)  
- **AI Engine:** OpenAI API / HuggingFace  
- **Database:** Firebase / MongoDB
- 🎙️ Voice Interaction: Users can talk to the AI and listen to responses

## 🛠️ Upcoming Features
- AI-generated daily wellness tips
- Gamification rewards for consistent mood tracking
